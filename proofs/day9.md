Main idea: a function can be studied as a mapping between sets, not just as an equation.

## Notation Learned

f: A → B means f is a function from set A to set B.

A is the domain.

B is the codomain.

The range/image is the set of outputs that the function actually reaches.

## Concepts Practiced

Injective means different inputs cannot give the same output.

To prove injective:
Assume f(a) = f(b), then prove a = b.

To disprove injective:
Find two different inputs that give the same output.

Surjective means every element in the codomain gets hit by the function.

To prove surjective:
Let y be an arbitrary element of the codomain, then find an input x such that f(x) = y.

To disprove surjective:
Find one element in the codomain that no input maps to.

## Problems Completed

### Problem 1

Let f: ℤ → ℤ be defined by:

f(n) = 2n + 1

Proved that f is injective.

### Problem 2

Let f: ℤ → ℤ be defined by:

f(n) = n²

Disproved that f is injective using a counterexample.

### Problem 3

Let f: ℤ → ℤ be defined by:

f(n) = n + 5

Proved that f is surjective.

Main proof habit learned:
After choosing x = y - 5, plug it back into the function to verify f(x) = y.

### Problem 4

Let f: ℤ → ℤ be defined by:

f(n) = 2n

Disproved that f is surjective by showing that 1 is in the codomain but cannot be hit by any integer input.

### Problem 5

Let f: ℤ → ℤ be defined by:

f(n) = 3n - 4

Proved that f is injective.

Then showed that f is not surjective by finding an integer in the codomain that no integer input maps to.

## Summary

Completed all 5 Day 9 function proof problems.

Main lesson:
For injectivity, prove equal outputs force equal inputs. For surjectivity, start with an arbitrary target output y and construct an input x that maps to it. If no such input exists for even one codomain value, the function is not surjective.
