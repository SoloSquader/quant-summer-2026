# Day 7 Proofs

## Overview

Completed Day 7 proof set focused on basic set notation and set-proof structure.

Main topics:

* set membership
* subsets
* union
* intersection
* complements
* proving set equality using both subset directions
* De Morgan’s Law

## Notation Practiced

x ∈ A means x is an element of A.

x ∉ A means x is not an element of A.

A ⊆ B means A is a subset of B.

A ∩ B means the intersection of A and B.

A ∪ B means the union of A and B.

Aᶜ means the complement of A.

## Proof Method Practiced

To prove A ⊆ B:

Start with an arbitrary element x ∈ A.

Use definitions to show x ∈ B.

Then conclude A ⊆ B.

To prove A = B:

Prove A ⊆ B.

Then prove B ⊆ A.

Then conclude A = B.

## Problems Completed

Problem 1:

Proved that for any sets A and B:

A ∩ B ⊆ A

Problem 2:

Proved that for any sets A and B:

A ⊆ A ∪ B

Problem 3:

Proved that for any sets A, B, and C:

If A ⊆ B and B ⊆ C, then A ⊆ C.

Problem 4:

Proved that for any sets A and B:

A ∩ B = B ∩ A

Problem 5:

Proved De Morgan’s Law:

(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
